# ระบบขยายเขตผู้ใช้น้ำ การประปาส่วนภูมิภาคเขต 6 (PWA Area 6 Expansion System)

ระบบแดชบอร์ดติดตาม ประเมินความคุ้มทุน และวิเคราะห์พิกัดแผนที่ผู้ใช้น้ำของโครงการขยายเขตจำหน่ายน้ำ ในพื้นที่ความรับผิดชอบของ กปภ.เขต 6 (ภาคตะวันออกเฉียงเหนือ) ครอบคลุม 8 สาขาเป้าหมายยุทธศาสตร์

---

## 🛠️ เทคโนโลยีที่ใช้งาน (Technology Stack)

*   **Frontend**: React (Vite), TailwindCSS, Leaflet Map (แผนที่พิกัด), Recharts (การแสดงผลกราฟ)
*   **Backend**: Node.js (Express API Server)
*   **Database**: MySQL Server 8.4 (พอร์ต `3306` ฐานข้อมูล `pwa6_expansion`)
    *   ระบบการดึงรายชื่อลูกค้าใช้การเชื่อมโยงข้อมูลภาษาไทยแบบ UTF-8 สมบูรณ์ และรองรับคอลัมน์วันที่สมัครใช้บริการแบบ `BGN_DATE` พร้อมตัวกรองปฏิทิน พ.ศ. อัตโนมัติ

## 💡 ฟีเจอร์การทำงานของระบบ (Key Features)

1.  **ภาพรวมรายโครงการ (Overview & Interactive Map)**
    *   วิเคราะห์สรุปผลงานเปรียบเทียบกับงบประมาณและเป้าหมาย
    *   ตัวกรองขั้นสูงตามปีงบประมาณ, กปภ.สาขา, ประเภทโครงการ และช่องค้นหาหลัก
    *   **แผนที่พิกัดผู้ใช้น้ำขยายเขต (Water Users Coordinates Mapping)**:
        *   เมื่อคลิกหมุดโครงการบนแผนที่ หรือปุ่ม "พิกัด" ในตาราง แผนที่จะโฟกัสและแสดงหมุดตำแหน่งของผู้ใช้น้ำทั้งหมด (สีเขียวเทอร์ควอยซ์) ในโครงการนั้นๆ
        *   แสดงแถบรายชื่อผู้ใช้น้ำทางขวา สามารถคลิกเพื่อเลื่อนแผนที่ (Pan) ไปยังตำแหน่งผู้ใช้น้ำรายนั้นๆ พร้อมแสดงรายละเอียดใน Popup อย่างครบถ้วน (สถานะการใช้น้ำ, รหัสผู้ใช้, เลขที่และขนาดมาตร, ประเภทการใช้น้ำ, หน่วยใช้น้ำสะสม, และที่อยู่อย่างละเอียด)

2.  **วิเคราะห์ยอดรายเดือนรายสาขา (Monthly Performance)**
    *   ตาราง Matrix Grid แสดงยอดผลงานแยกรายเดือนและสาขา พร้อมระบบ Heatmap ไฮไลท์ประสิทธิภาพเชิงพื้นที่
    *   กราฟแนวโน้มแสดงสถิติผู้ใช้น้ำที่เกิดขึ้นสะสมรายเดือน
    *   ระบบ Drill-down คลิกที่ช่องข้อมูลในตารางเพื่อเจาะลึกดูรายละเอียดโครงการย่อยที่เกี่ยวข้องในแต่ละเดือน

3.  **แดชบอร์ดประเมินจุดคุ้มทุนสะสม (Break-even Analysis)**
    *   วิเคราะห์ประสิทธิภาพการบรรลุเป้าหมายตามเกณฑ์ระยะเวลา (เกณฑ์ 5 ปีสำหรับงบลงทุน/อุดหนุน และเกณฑ์ 1 ปีสำหรับท่อเข้าซอย)
    *   กราฟเปรียบเทียบเป้าหมายสะสมรายปีกับผลงานที่เกิดขึ้นจริง เพื่อประเมินความสำเร็จของโครงการเชิงลึก

## 📈 เกณฑ์การประเมินจุดคุ้มทุนอย่างละเอียด (Detailed Break-even Evaluation Criteria)

การประเมินจุดคุ้มทุนของแต่ละโครงการในระบบนี้ ได้รับการออกแบบตามประเภทโครงการและการคำนวณสถิติสะสม ดังรายละเอียดต่อไปนี้:

### 1. การแบ่งเกณฑ์ตามประเภทโครงการ (Project Classification)
*   **โครงการประเภทที่ 1, 2, 3 (โครงการขยายเขตปกติ / โครงการขนาดใหญ่ / โครงการตามแผนงานยุทธศาสตร์)**
    *   ใช้ **เกณฑ์ประเมินสะสมระยะเวลา 5 ปี** นับตั้งแต่ปีที่โครงการแล้วเสร็จ
*   **โครงการประเภทที่ 4 (งานวางท่อเข้าซอย - Soi Pipe Laying)**
    *   ใช้ **เกณฑ์ประเมินสะสมระยะเวลา 1 ปี** โดยพิจารณาเฉพาะปีที่แล้วเสร็จโครงการ

### 2. รายละเอียดสัดส่วนเป้าหมายสะสม (Target Allocation Percentage)
สำหรับโครงการที่มีเกณฑ์การประเมินสะสม 5 ปี (ประเภท 1, 2, 3) เป้าหมายจำนวนผู้ใช้น้ำสะสมจะถูกปันส่วนออกเป็นรายปีตามสูตรดังนี้:
*   **ปีที่ 1 (Year 1)**: เป้าหมายสะสมอยู่ที่ **40%** ของเป้าหมายผู้ใช้น้ำโครงการรวม (`target_users`)
*   **ปีที่ 2 (Year 2)**: เป้าหมายสะสมเพิ่มอีก 15% (รวมเป็น **55%**)
*   **ปีที่ 3 (Year 3)**: เป้าหมายสะสมเพิ่มอีก 15% (รวมเป็น **70%**)
*   **ปีที่ 4 (Year 4)**: เป้าหมายสะสมเพิ่มอีก 15% (รวมเป็น **85%**)
*   **ปีที่ 5 (Year 5)**: เป้าหมายสะสมเพิ่มอีก 15% (รวมเป็น **100%**)

### 3. เกณฑ์การกรองและนับจำนวนผู้ใช้น้ำจริง (Actual Users Filtering Rule)
ผู้ใช้น้ำจะถูกนับเป็นยอดผลงานของโครงการขยายเขตขยายระบบก็ต่อเมื่อผ่านเกณฑ์การกรองวันสมัครใช้บริการ:
*   **ฟิลด์วันที่เริ่มต้นใช้งาน**: ระบบจะดึงข้อมูลวันที่เริ่มใช้งานเป็นหลักจากคอลัมน์ **`BGN_DATE`** ในตาราง `customer` (ระบุปีเป็น ค.ศ. และจะถูกแปลงเป็นปี พ.ศ. โดยบวกเพิ่ม 543 ปีอัตโนมัติ) และหากไม่พบข้อมูลในตารางดังกล่าว จะใช้ฟิลด์ **`bgncustdt`** (รูปแบบ `YYMMDD` ปฏิทิน พ.ศ.) ในตาราง `proj_cus` เป็นตัวสำรองแทน
*   **เกณฑ์การตรวจสอบช่วงเวลา**: ระบบจะนำวันที่สมัครใช้บริการมาเปรียบเทียบกับ **วันที่แล้วเสร็จโครงการ (`completed_date`)** ในตาราง `plan_master` โดย **ผู้ใช้น้ำรายนั้นๆ จะต้องเริ่มใช้งานในวันหรือหลังจากวันที่โครงการก่อสร้างแล้วเสร็จเท่านั้น** หากใช้น้ำก่อนวันแล้วเสร็จโครงการจะไม่ถูกนับเป็นยอดผลงาน
*   **การควบรวมปีแรก (Year 0 + Year 1)**: เนื่องจากปีที่แล้วเสร็จโครงการ (Year 0) อาจมีระยะเวลานับผลงานไม่เต็มปีงบประมาณ **ในการประเมินปีที่ 1 ผลงานจริงสะสมจึงคิดจาก "ผลงานของปีที่แล้วเสร็จ (Year 0) + ผลงานของปีประเมินปีที่ 1 (Year 1) รวมกัน"** เพื่อให้ความคุ้มครองสถิติการเชื่อมต่อในช่วงเริ่มต้นของโครงการ

### 4. การตัดสินสถิติจุดคุ้มทุน
*   **การคุ้มทุนรายปี**: โครงการบรรลุจุดคุ้มทุนในปีนั้นๆ หาก **ยอดผู้ใช้สะสมจริง ณ ปีประเมิน $\ge$ เป้าหมายสะสม ณ ปีประเมิน**
*   **การคำนวณตำแหน่งโครงการเฉลี่ย**: สคริปต์ [migrate.js](file:///d:/Antigravity/Customer%20Project/backend/migrate.js) จะนำตำแหน่งพิกัดดาวเทียม (Latitude, Longitude) ของผู้ใช้น้ำทั้งหมดที่ผ่านการกรองและอยู่ภายใต้สัญญามาทำคำนวณเป็นค่าเฉลี่ยทางคณิตศาสตร์ (Average Coordinate) เพื่อใช้อัปเดตและแสดงพิกัดที่แท้จริงของโครงการบนแผนที่หลัก
