# ระบบติดตามและประเมินผลโครงการวางท่อขยายเขตจำหน่ายน้ำ กปภ.ข.6 (PWA Area 6 Expansion System)

ระบบแดชบอร์ดติดตาม ประเมินความคุ้มทุน และวิเคราะห์พิกัดแผนที่ผู้ใช้น้ำของโครงการวางท่อขยายเขตจำหน่ายน้ำ ในพื้นที่ความรับผิดชอบของ กปภ.เขต 6 (ภาคตะวันออกเฉียงเหนือ) ครอบคลุม 8 สาขาเป้าหมายยุทธศาสตร์ ดึงข้อมูลพิกัดและยอดติดตั้งมิเตอร์ใช้น้ำประปาโดยตรงประสานร่วมกับระบบ PCIS

---

## 🛠️ เทคโนโลยีที่ใช้งาน (Technology Stack)

*   **Frontend**: React 19 (Vite), TailwindCSS v4, Leaflet Map (แผนที่ระบบภูมิสารสนเทศ), Recharts (กราฟสรุปสถิติ), Lucide React (ชุดไอคอน)
*   **Backend**: Node.js, Express API Server (CommonJS)
*   **Database**: MySQL Server 8.4 (พอร์ต `3306` ฐานข้อมูลเริ่มต้น `pwa6_expansion` หรือปรับแต่งผ่าน `backend/.env`)
    *   ระบบเชื่อมต่อข้อมูลใช้ชุดรหัสอักขระภาษาไทยและเปรียบเทียบแบบ UTF-8 (`utf8mb4_unicode_ci`) สมบูรณ์ เพื่อหลีกเลี่ยงข้อผิดพลาด Collation Mismatch
    *   รองรับการประเมินจากคอลัมน์สมัครใช้น้ำแบบ `BGN_DATE` (ตาราง `customer`) โดยแปลงปี ค.ศ. เป็น พ.ศ. อัตโนมัติ และระบบวันที่สำรอง `bgncustdt` (ตาราง `proj_cus`)

## 💡 ฟีเจอร์การทำงานของระบบ (Key Features)

1.  **รายงานข้อมูลรายโครงการ & แผนที่ระบบภูมิสารสนเทศ (Overview & Interactive Map)**
    *   การ์ดสรุป KPI (จำนวนโครงการ, วงเงินงบประมาณรวม, เป้าหมายผู้ใช้สะสม และผู้ใช้น้ำจริง)
    *   แผนที่รวมหมุดเฉลี่ยโครงการ และแผนที่แสดงพิกัดผู้ใช้น้ำจริง (สีเขียวเทอร์ควอยซ์) สามารถคลิกรายชื่อเพื่อเคลื่อนแผนที่ไปยังพิกัดลูกค้า (Pan)
    *   ตารางรายละเอียดโครงการ ค้นหา คัดกรอง ค้นรหัส หรือส่งออกเป็น CSV
    *   **การแสดงเลขที่สัญญา (Contract Number):** แสดงเลขที่สัญญา (เลขที่สัญญา/วันก่อสร้างแล้วเสร็จ) บนการ์ดข้อมูลและหัวข้อป๊อปอัพรายชื่อผู้ใช้น้ำ เพื่อให้พนักงานและผู้ดูแลระบบสามารถตรวจสอบเอกสารอ้างอิงได้อย่างชัดเจน
    *   **ปุ่มแก้ไขสัญญา (Planning & Admin เท่านั้น):** สามารถแก้ไขเลขที่สัญญาและวันก่อสร้างแล้วเสร็จได้ทันทีจากหน้าระบบ
2.  **วิเคราะห์ยอดรายเดือนรายสาขา (Monthly Performance Matrix)**
    *   ตาราง Matrix Grid สรุปยอดผู้ใช้รายเดือนและสาขา พร้อม Heatmap แสดงความหนาแน่นเชิงผลสัมฤทธิ์
    *   ระบบเจาะลึกข้อมูล (Drill-down) คลิกที่ช่องตัวเลขเพื่อแสดงรายชื่อลูกค้าจริงในเดือนนั้นๆ (พร้อมแสดงเลขที่สัญญาประกอบในรายการย่อย)
3.  **ประเมินจำนวนผู้ใช้น้ำตามเป้าหมายโครงการ (Break-even Analysis)**
    *   แสดงเป้าหมายสะสม (Cumulative Target) เทียบกับผลงานสะสมที่เกิดขึ้นจริง (Cumulative Actual) เป็นกราฟเส้น
    *   เรียงลำดับโครงการใน Dropdown อ้างอิงตามอัตราความสำเร็จสูงสุดลงไปต่ำสุด พร้อมจุดสีบอกระดับความสำเร็จ (🟢 เขียว $\ge 100\%$, 🟡 ส้ม $\ge 70\%$, 🔴 แดง $< 70\%$)
4.  **วิเคราะห์ปริมาณการใช้น้ำสะสมและค่าน้ำสะสม (Water Consumption Analysis)**
    *   วิเคราะห์ประวัติการเปิดมิเตอร์ใช้น้ำ ค่าน้ำสะสม (บาท) และปริมาณการใช้น้ำรวม (ลบ.ม.)
    *   วิเคราะห์และเจาะลึกประวัติใช้น้ำรายบิลรายเดือนย้อนหลัง 12 เดือน (M0 ถึง M12) ของผู้ใช้น้ำแต่ละรายในโครงการ เพื่อตรวจสอบมาตรชำรุด หรือลูกค้าย้ายออก
5.  **แผงควบคุมระบบการจัดการสิทธิ์ (Admin Console)**
    *   แผงจัดการผู้ใช้งาน (การระงับบัญชี/เปิดใช้งาน)
    *   การกำหนด Role ระดับสิทธิ์ผ่านเมนูดรอปดาวน์
    *   **การนำเข้าข้อมูลโครงการด้วยไฟล์ CSV (Bulk CSV Import):** ส่วนช่วยงาน Admin ในการนำเข้าข้อมูลโครงการขยายเขตจำนวนมากผ่านการอัพโหลดไฟล์ CSV พร้อมฟังก์ชันดาวน์โหลดไฟล์เทมเพลตมาตรฐาน ระบบตรวจสอบความถูกต้อง (Validation Error Highlight) และตารางแสดงตัวอย่างความผิดพลาดแบบเรียลไทม์ โดยข้อมูลจะบันทึกเข้าสู่ตาราง `projects` และ `plan_master` ภายใต้ Database Transaction พร้อมสั่งรันการประมวลผลคำนวณ KPI ใหม่ทันทีหลังทำงานเสร็จ
    *   ประวัติการทำธุรกรรมระบบ (System Audit Logs) แสดงบันทึกความปลอดภัย

## 🔑 การแบ่งแยกสิทธิ์ผู้ใช้งาน (Access Roles & Security System)

ระบบแบ่งระดับสิทธิ์การดำเนินงานออกเป็น **3 ระดับ** เพื่อควบคุมขอบเขตความมั่นคงปลอดภัย:

| ระดับสิทธิ์ | ค่าสำคัญ (Level) | ขอบเขตหน้าที่และความปลอดภัย |
| :--- | :---: | :--- |
| **ผู้ดูแลระบบ (Admin)** | **$\ge$ 100** | สิทธิ์สูงสุดในระบบ ทำรายการได้ทุกอย่าง เข้าใช้งานหน้า **Admin Console** สลับสิทธิ์ผู้ใช้ ระงับบัญชี ดู Audit logs และปรับปรุงฐานข้อมูลได้ |
| **เจ้าหน้าที่แผนงาน (Planning)** | **50 - 99** | สิทธิ์ด้านข้อมูลแผนงาน สามารถเพิ่มโครงการใหม่ แก้ไขเลขที่สัญญา และวันที่เสร็จสิ้นโครงการได้ (มีสิทธิ์เขียนข้อมูลผ่าน `requireWriteAuth` Guard) แต่ไม่สามารถเข้าเมนูจัดการแอดมินได้ |
| **ผู้ใช้งานทั่วไป (User/Viewer)** | **0 - 49** | สิทธิ์เริ่มต้นของบัญชีลงทะเบียนใหม่ สามารถเข้าชมและสืบค้นข้อมูลใน Dashboard ทุกแถบได้แบบอ่านอย่างเดียว (Read-only) ไม่สามารถเพิ่ม/แก้ไขข้อมูลใดๆ ได้ |

## 📈 เกณฑ์การประเมินผลโครงการอย่างละเอียด (Detailed Evaluation Logic)

### 1. เกณฑ์ตามประเภทโครงการ
*   **โครงการประเภท 1, 2, 3 (งบปกติ / เงินลงทุน / อุดหนุน / กระตุ้นเศรษฐกิจ):** ประเมินผลสะสม **5 ปี** นับจากปีที่แล้วเสร็จ
*   **โครงการประเภท 4 (วางท่อเข้าซอย):** ประเมินผลระยะสั้น **1 ปี** (เป้าหมาย 100% ในปีที่แล้วเสร็จโครงการ)

### 2. สัดส่วนเป้าหมายสะสม 5 ปี
*   **ปีที่ 1 (Year 1)**: เป้าหมายสะสม **40%** (รวมผลงาน Year 0 และ Year 1 เข้าด้วยกันเพื่อความยุติธรรมด้านเวลา)
*   **ปีที่ 2 (Year 2)**: สะสมเพิ่มอีก 15% (รวมเป็น **55%**)
*   **ปีที่ 3 (Year 3)**: สะสมเพิ่มอีก 15% (รวมเป็น **70%**)
*   **ปีที่ 4 (Year 4)**: สะสมเพิ่มอีก 15% (รวมเป็น **85%**)
*   **ปีที่ 5 (Year 5)**: สะสมเพิ่มอีก 15% (รวมเป็น **100%**)

### 3. เกณฑ์การกรองและนับผู้ใช้น้ำประปา
*   ผู้ใช้น้ำจะต้องมีวันติดตั้ง (ดึงจาก `BGN_DATE` ค.ศ. แปลงเป็น พ.ศ. หรือใช้ `bgncustdt` เป็นคีย์สำรอง) **หลังวันเสร็จสิ้นโครงการจริง (`completed_date`) เท่านั้น**
*   **กรอบเวลาการประเมิน (Timeframe Capping)**: ข้อมูลการติดตั้งใช้น้ำหลังพ้นกรอบการประเมิน (ปีที่ 6 เป็นต้นไปสำหรับประเภท 1-3) จะถูกตัดออกจากการนับผลงานและรายงานค่าน้ำ เพื่อความถูกต้องของสัญญารายการโครงการ

## 🛠️ สคริปต์ยูทิลิตี้จัดการฐานข้อมูล (Database Management & Utilities)

สำหรับการนำเข้าหรือจัดการข้อมูล ดำเนินการผ่านคำสั่ง Command Line ในโฟลเดอร์ `backend/`:

1.  **ซิงค์พิกัดและคำนวณผลงานสะสมใหม่:**
    รันทุกครั้งที่มีการอัปเดตข้อมูลตารางดิบ หรือแก้ไของค์ประกอบสัญญา เพื่อประมวลผลสถิติและหาพิกัดศูนย์กลางของโครงการใหม่:
    ```bash
    cd backend
    node update_data.js
    ```
2.  **ย้ายข้อมูลและรีเซ็ตระบบฐานข้อมูลใหม่ทั้งหมด (Full Migration):**
    ```bash
    cd backend
    node migrate.js
    ```
3.  **แก้ปัญหา Collation Mismatch (รหัสอักขระภาษาไทยไม่เข้ากัน):**
    ```bash
    cd backend
    node fix_collation.js
    node fix_projects_collation.js
    ```
