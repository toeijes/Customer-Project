# ระบบขยายเขตผู้ใช้น้ำ การประปาส่วนภูมิภาคเขต 6 (PWA Area 6 Expansion System)

ระบบแดชบอร์ดติดตาม ประเมินความคุ้มทุน และวิเคราะห์พิกัดแผนที่ผู้ใช้น้ำของโครงการขยายเขตจำหน่ายน้ำ ในพื้นที่ความรับผิดชอบของ กปภ.เขต 6 (ภาคตะวันออกเฉียงเหนือ) ครอบคลุม 8 สาขาเป้าหมายยุทธศาสตร์

---

## 🛠️ เทคโนโลยีที่ใช้งาน (Technology Stack)

*   **Frontend**: React 19 (Vite), TailwindCSS v4, Leaflet Map (แผนที่ปักหมุดพิกัด), Recharts (การแสดงผลกราฟ), Lucide React (ไอคอน)
*   **Backend**: Node.js, Express API Server (CommonJS)
*   **Database**: MySQL Server 8.4 (พอร์ต `3306` ฐานข้อมูลเริ่มต้น `pcis` หรือปรับแต่งผ่าน `backend/.env`)
    *   ระบบประมวลผลและเชื่อมโยงข้อมูลใช้การเชื่อมโยงข้อมูลภาษาไทยแบบ UTF-8 (`utf8mb4_unicode_ci`) สมบูรณ์ เพื่อหลีกเลี่ยงข้อผิดพลาด Collation Mismatch
    *   รองรับคอลัมน์วันที่สมัครใช้บริการแบบ `BGN_DATE` (ตาราง `customer`) พร้อมแปลงปี ค.ศ. เป็น พ.ศ. และระบบวันที่สำรอง `bgncustdt` (ตาราง `proj_cus`)

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน (Installation & Quick Start)

### 1. การนำเข้าและเตรียมฐานข้อมูลจริง (Database Setup for Real Data)
ก่อนเริ่มใช้งานระบบ จำเป็นต้องเตรียมฐานข้อมูล MySQL ให้เรียบร้อย:
1. สร้างฐานข้อมูลใหม่ชื่อ `pcis` (หรือเปลี่ยนชื่อดาต้าเบสในไฟล์ `backend/.env`) ภายใต้ Encoding `utf8mb4` และ Collation `utf8mb4_unicode_ci`
2. นำเข้าข้อมูลดิบจากไฟล์ SQL ที่อยู่บริเวณรูทโฟลเดอร์โครงการตามลำดับดังนี้:
   ```powershell
   # นำเข้าโครงสร้างรายละเอียดลูกค้าและบิลค่าน้ำรายเดือน
   mysql -u root -p pcis < customer.sql
   mysql -u root -p pcis < debt_trn.sql
   mysql -u root -p pcis < proj_cus.sql
   mysql -u root -p pcis < plan_master.sql
   mysql -u root -p pcis < pcis2.sql
   ```
3. นำเข้าข้อมูลระบบแดชบอร์ดและสกีมาความปลอดภัย (ย้ายโครงการดิบเข้าตารางประเมินผล):
   ```bash
   cd backend
   node migrate.js
   ```
4. ประมวลสถิติติดตั้งสะสมเฉลี่ย และจัดทำพิกัดเฉลี่ยของโครงการ:
   ```bash
   node update_data.js
   ```

### 2. วิธีรันแบบอัตโนมัติ (แนะนำ)
ดับเบิลคลิกไฟล์ **`start_project.bat`** ที่โฟลเดอร์หลัก เพื่อเปิดใช้งานบริการทั้งหมดและแสดงหน้าเว็บโดยอัตโนมัติ:
1. รันเซิร์ฟเวอร์ MySQL (พอร์ต `3306`)
2. รันเซิร์ฟเวอร์ Backend API (พอร์ต `5000`)
3. รันเซิร์ฟเวอร์ Frontend React (พอร์ต `5173`)
4. เปิดเว็บบราวเซอร์ไปยังหน้าเว็บหลักที่ [http://localhost:5173](http://localhost:5173)

## 💡 ฟีเจอร์การทำงานของระบบ (Key Features)

1. **ภาพรวมรายโครงการ (Overview & Interactive Map)**
   * วิเคราะห์สรุปผลงานเปรียบเทียบกับงบประมาณและเป้าหมายผู้ใช้น้ำสะสม
   * ตัวกรองขั้นสูงตามปีงบประมาณ, กปภ.สาขา, ประเภทโครงการ และช่องค้นหารหัสหรือชื่อโครงการ
   * **แผนที่พิกัดผู้ใช้น้ำขยายเขต (Water Users Coordinates Mapping)**:
     * เมื่อคลิกหมุดโครงการบนแผนที่ หรือปุ่ม "พิกัด" ในตาราง แผนที่จะโฟกัสและแสดงหมุดตำแหน่งของผู้ใช้น้ำทั้งหมด (สีเขียวเทอร์ควอยซ์) ในโครงการนั้นๆ
     * แสดงแถบรายชื่อผู้ใช้น้ำทางขวา สามารถคลิกเพื่อเลื่อนแผนที่ (Pan) ไปยังตำแหน่งผู้ใช้น้ำรายนั้นๆ พร้อมแสดงรายละเอียดใน Popup อย่างครบถ้วน (สถานะการใช้น้ำ, รหัสผู้ใช้, เลขที่และขนาดมาตร, ประเภทการใช้น้ำ, หน่วยใช้น้ำสะสม, และที่อยู่อย่างละเอียด)

2. **วิเคราะห์ยอดรายเดือนรายสาขา (Monthly Performance)**
   * ตาราง Matrix Grid แสดงยอดผลงานแยกรายเดือนและสาขา พร้อมระบบ Heatmap ไฮไลท์ประสิทธิภาพเชิงพื้นที่
   * กราฟแนวโน้มแสดงสถิติผู้ใช้น้ำที่เกิดขึ้นสะสมรายเดือน
   * ระบบ Drill-down คลิกที่ช่องข้อมูลในตารางเพื่อเจาะลึกดูรายละเอียดโครงการย่อยที่เกี่ยวข้องในแต่ละเดือน

3. **แดชบอร์ดประเมินจุดคุ้มทุนสะสม (Break-even Analysis)**
   * วิเคราะห์ประสิทธิภาพการบรรลุเป้าหมายตามเกณฑ์ระยะเวลา (เกณฑ์ 5 ปีสำหรับงบลงทุน/อุดหนุน และเกณฑ์ 1 ปีสำหรับท่อเข้าซอย)
   * กราฟเปรียบเทียบเป้าหมายสะสมรายปีกับผลงานที่เกิดขึ้นจริง เพื่อประเมินความสำเร็จของโครงการเชิงลึก
   * **การเรียงลำดับโครงการใน Dropdown**:
     * รายการโครงการใน Dropdown สำหรับเลือกประเมินจุดคุ้มทุน จะถูกจัดเรียงตามลำดับจาก **โครงการที่มีอัตราผลสัมฤทธิ์ (Achievement Rate) สูงสุด ไปหาต่ำสุด** เพื่อความสะดวกในการติดตามโครงการที่ประสบความสำเร็จสูงและเพ่งเล็งโครงการที่มีปัญหา
   * **ระบบแสดงสถานะและสีความสำเร็จ (Color Indicators)**:
     * ใน Dropdown จะแสดงสัญลักษณ์จุดสีนำหน้าโครงการดังนี้เพื่อช่วยจำแนกสถานะ:
       * 🟢 **สีเขียว (`●`)**: บรรลุเกณฑ์การประเมินสะสมเรียบร้อยแล้ว (อัตราความสำเร็จ $\ge 100\%$)
       * 🟡 **สีเหลือง/ส้ม (`●`)**: ปานกลาง / รอการเติบโตของผู้ใช้น้ำเพิ่มเติม (อัตราความสำเร็จ $\ge 70\%$ และ $< 100\%$)
       * 🔴 **สีแดง (`●`)**: ค่อนข้างต่ำ / ต้องติดตามความคืบหน้าอย่างใกล้ชิด (อัตราความสำเร็จ $< 70\%$)

4. **ระบบวิเคราะห์ปริมาณการใช้น้ำสะสม (Water Consumption Analysis)**
   * วิเคราะห์พฤติกรรมการใช้น้ำประปาจริงและสรุปยอดจัดเก็บค่าน้ำของผู้ใช้น้ำภายใต้โครงการขยายเขต (ดึงข้อมูลประวัติบิลรายเดือนจากตาราง `debt_trn`)
   * แสดงตัวชี้วัดหลัก: จำนวนผู้ใช้น้ำที่เกิดปริมาณน้ำจริง, ยอดจำนวนรอบบิลทั้งหมด, ยอดปริมาณการใช้น้ำสะสมรวม (ลูกบาศก์เมตร), และยอดเงินค่าน้ำสะสมรวม (บาท)
   * กราฟเปรียบเทียบยอดการใช้น้ำและยอดจัดเก็บแยกตามปีงบประมาณ และกราฟแนวโน้มรายเดือน (เรียงจาก ต.ค. ถึง ก.ย.)
   * ตารางเปรียบเทียบรายได้แยกตามโครงการ (เรียงจากยอดใช้น้ำมากที่สุดไปหาน้อยที่สุด) และรายสาขา เพื่อวัดประสิทธิภาพทางการเงินและการใช้น้ำจริงของโครงการขยายเขต
   * ระบบแสดงรายชื่อผู้ใช้น้ำพร้อมสถานะมาตร ขนาดมาตร ยอดใช้น้ำสะสมรวม และมีฟังก์ชัน Drill-down เพื่อดูรายละเอียดบิลการใช้น้ำรายเดือนของลูกค้ารายบุคคล

## 📈 เกณฑ์การประเมินจุดคุ้มทุนอย่างละเอียด (Detailed Break-even Evaluation Criteria)

การประเมินจุดคุ้มทุนของแต่ละโครงการในระบบนี้ ได้รับการออกแบบตามประเภทโครงการและการคำนวณสถิติสะสม ดังรายละเอียดต่อไปนี้:

### 1. การแบ่งเกณฑ์ตามประเภทโครงการ (Project Classification)
*   **โครงการประเภทที่ 1, 2, 3 (โครงการขยายเขตปกติ / โครงการขนาดใหญ่ / โครงการตามแผนงานยุทธศาสตร์)**
    *   ใช้ **เกณฑ์ประเมินสะสมระยะเวลา 5 ปี** นับตั้งแต่ปีที่โครงการแล้วเสร็จ
*   **โครงการประเภทที่ 4 (งานวางท่อเข้าซอย - Soi Pipe Laying)**
    *   ใช้ **เกณฑ์ประเมินสะสมระยะเวลา 1 ปี** โดยพิจารณาเฉพาะปีที่แล้วเสร็จโครงการ

### 2. รายละเอียดสัดส่วนเป้าหมายสะสม (Target Allocation Percentage)
สำหรับโครงการที่มีเกณฑ์การประเมินสะสม 5 ปี (ประเภท 1, 2, 3) เป้าหมายจำนวนผู้ใช้น้ำสะสมจะถูกปันส่วนออกเป็นรายปีตามสูตรดังนี้:
*   **ปีที่ 1 (Year 1)**: เป้าหมายสะสมอยู่ที่ **40%** ของเป้าหมายผู้ใช้น้ำโครงการรวม (`target_users`)
*   **ปีที่ 2 (Year 2)**: เป้าหมายสะสมเพิ่มอีก 15% (รวมเป็น **55%**)
*   **ปีที่ 3 (Year 3)**: เป้าหมายสะสมเพิ่มอีก 15% (รวมเป็น **70%**)
*   **ปีที่ 4 (Year 4)**: เป้าหมายสะสมเพิ่มอีก 15% (รวมเป็น **85%**)
*   **ปีที่ 5 (Year 5)**: เป้าหมายสะสมเพิ่มอีก 15% (รวมเป็น **100%**)

### 3. เกณฑ์การกรองและนับจำนวนผู้ใช้น้ำจริง (Actual Users Filtering Rule)
ผู้ใช้น้ำจะถูกนับเป็นยอดผลงานของโครงการขยายเขตขยายระบบก็ต่อเมื่อผ่านเกณฑ์การกรองวันสมัครใช้บริการ:
*   **ฟิลด์วันที่เริ่มต้นใช้งาน**: ระบบจะดึงข้อมูลวันที่เริ่มใช้งานเป็นหลักจากคอลัมน์ **`BGN_DATE`** ในตาราง `customer` (ระบุปีเป็น ค.ศ. และจะถูกแปลงเป็นปี พ.ศ. โดยบวกเพิ่ม 543 ปีอัตโนมัติ) และหากไม่พบข้อมูลในตารางดังกล่าว จะใช้ฟิลด์ **`bgncustdt`** (รูปแบบ `YYMMDD` ปฏิทิน พ.ศ.) ในตาราง `proj_cus` เป็นตัวสำรองแทน
*   **เกณฑ์การตรวจสอบช่วงเวลา**: ระบบจะนำวันที่สมัครใช้บริการมาเปรียบเทียบกับ **วันที่แล้วเสร็จโครงการ (`completed_date`)** ในตาราง `plan_master` โดย **ผู้ใช้น้ำรายนั้นๆ จะต้องเริ่มใช้งานในวันหรือหลังจากวันที่โครงการก่อสร้างแล้วเสร็จเท่านั้น** หากใช้น้ำก่อนวันแล้วเสร็จโครงการจะไม่ถูกนับเป็นยอดผลงาน
*   **การควบรวมปีแรก (Year 0 + Year 1)**: เนื่องจากปีที่แล้วเสร็จโครงการ (Year 0) อาจมีระยะเวลานับผลงานไม่เต็มปีงบประมาณ **ในการประเมินปีที่ 1 ผลงานจริงสะสมจึงคิดจาก "ผลงานของปีที่แล้วเสร็จ (Year 0) + ผลงานของปีประเมินปีที่ 1 (Year 1) รวมกัน"** เพื่อให้ความคุ้มครองสถิติการเชื่อมต่อในช่วงเริ่มต้นของโครงการ

### 4. การประมวลผลทศนิยมและการปัดเศษ (Decimal Rounding Policy)
*   **การคำนวณผู้ใช้น้ำเป้าหมายสะสมรายปี**: เนื่องจากยอดเป้าหมายถูกปันส่วนตามสัดส่วนร้อยละ (40%, 15% ในแต่ละปี) หากผลการคำนวณเป็นทศนิยม ระบบจะทำการปัดเศษเป็นจำนวนเต็มผู้ใช้น้ำ (ราย) ด้วยฟังก์ชัน **`Math.round()`** (ปัดเศษหลักตามปกติ: ทศนิยมตั้งแต่ `.5` ขึ้นไปจะปัดขึ้น น้อยกว่า `.5` จะปัดลง)
*   **อัตราความสำเร็จของโครงการ (Achievement Rate)**: คำนวณจากยอดผู้ใช้น้ำสะสมที่เกิดขึ้นจริงหารด้วยเป้าหมายสะสมในปีนั้นๆ แสดงผลในรูปแบบเปอร์เซ็นต์โดยปัดทศนิยมเป็น **2 ตำแหน่ง** (`.toFixed(2)`) เสมอในส่วนติดต่อผู้ใช้งาน

### 5. การตัดสินสถิติจุดคุ้มทุนและการหาพิกัดโครงการ
*   **การคุ้มทุนรายปี**: โครงการบรรลุจุดคุ้มทุนในปีนั้นๆ หาก **ยอดผู้ใช้สะสมจริง ณ ปีประเมิน $\ge$ เป้าหมายสะสม ณ ปีประเมิน**
*   **การคำนวณตำแหน่งโครงการเฉลี่ย**: สคริปต์ [migrate.js](file:///d:/Antigravity/Customer%20Project/backend/migrate.js) และ [update_data.js](file:///d:/Antigravity/Customer%20Project/backend/update_data.js) จะนำตำแหน่งพิกัดดาวเทียม (Latitude, Longitude) ของผู้ใช้น้ำทั้งหมดที่ผ่านการกรองและอยู่ภายใต้สัญญามาทำคำนวณเป็นค่าเฉลี่ยทางคณิตศาสตร์ (Average Coordinate) เพื่อใช้อัปเดตและแสดงพิกัดที่แท้จริงของโครงการบนแผนที่หลัก
